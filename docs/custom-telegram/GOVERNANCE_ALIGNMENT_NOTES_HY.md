# Custom Telegram + AI v1.0 — Governance Alignment Notes

**Փուլ՝ Phase A · Կարգավիճակ՝ Proposed corrections · Phase B՝ NOT AUTHORIZED։**

Այս գրառումը փաստագրում է բաց հակասությունները, հաստատման սահմանները և հետագա խմբագրման առաջարկները։ [Master Architecture v1.0-ի](MEDUZELLAR_CUSTOM_TELEGRAM_MASTER_ARCHITECTURE_HY.md) CT-DEC-001–016-ը պահպանում են Owner-ի հաստատած դոմենային ուղղությունների կարգավիճակը։ Սույն գրառման առաջարկները դեռ պահանջում են համապատասխան Owner կամ Shared Platform հաստատում։

## Գործող պահանջներ

- [AGENTS.md-ի առաջնահերթությունը](../../AGENTS.md#decision-precedence) կառավարում է որոշումների իրավասությունը։ [Repository security invariants-ը](../../AGENTS.md#security-invariants) պարտադիր են։ Դրանք ներառում են secrets/credentials-ի պաշտպանություն, արտաքին input-ի validation, server-side authorization, անվտանգ password hashing՝ գաղտնաբառ պահելիս, parameterized queries և անվտանգ errors/logs։
- Պարտադիր են CORS allowlist-ը, CSRF պաշտպանությունը և առանձին WebSocket Origin/session/resource authorization ստուգումները։ Չլուծված Critical dependency vulnerability-ն կանգնեցնում է ազդված աշխատանքը։ Remediation ticket-ը գրանցում է ուղղումը։ Գործող կարգով անվտանգության բացառություն չկա։ [Security rule](../../.cursor/rules/08-security.mdc)
- [Marketplace ADR-009](../marketplace/ADR-009-MARKETPLACE-PLANNING-SIGN-OFF_HY.md)-ը և [Marketplace Governance Alignment Notes-ը](../marketplace/GOVERNANCE_ALIGNMENT_NOTES_HY.md) շարունակում են սահմանել իրենց ոլորտի որոշումներն ու մեկնաբանությունները։ Marketplace-ը տնօրինում է listing/order/grant/support case-ի վիճակը և կարող է իրականացնել core commerce-ը առանց Messenger-ի։ [Marketplace Shared Platform handoff](../marketplace/MARKETPLACE_SHARED_PLATFORM_DEPENDENCY_HANDOFF_HY.md)

## Scope և հետագծելիություն

CT-DEC-003/005-ի text-first և original-plus-translation ուղղությունները, CT-DEC-006/007/008-ի P1 հնարավորությունները, CT-DEC-010-ի Cloud Chat-ը և CT-DEC-011-ի AI-ից անկախ core-ը պահպանվում են։ Փոփոխվող առաջարկները վերաբերում են protocol semantics-ին, shared սկզբունքների քարտեզագրմանը և անվտանգության ստուգելի պայմաններին։ Ցանկացած scope փոփոխություն գրանցվում է առանձին Owner որոշմամբ՝ համապատասխան CT-DEC/FR/AT հղումներով։ v1.0-ի §12-ի փուլային կանոնը և Marketplace sign-off-ի սահմանները շարունակում են գործել։
