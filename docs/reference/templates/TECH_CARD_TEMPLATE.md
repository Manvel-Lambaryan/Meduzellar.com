# Նախագծի տեխնոլոգիական քարտ

> Դատարկ ձևանմուշ է։ Պատճենելը որոշում չի ստեղծում և չի հաստատում stack։
> Լրացվում է միայն պլանավորման փուլում, սեփականատիրոջ հաստատմամբ։
> **Մի սկսիր կոդ, սխեմա կամ vendor-ի միացում, քանի դեռ համապատասխան արժեքի Decision state-ը Approved չէ։**

**Նախագիծ.** [Անվանում]
**Չափ.** [դատարկ, մինչև հաստատում]
**Ամսաթիվ.** YYYY-MM-DD
**Փաստաթղթի կարգավիճակ.** սևագիր / հաստատված / ավարտված

Փաստաթղթի կարգավիճակը և Decision state-ը տարբեր բաներ են։ Փաստաթուղթը կարող է սևագիր լինել, մինչդեռ ոչ մի տեխնոլոգիա դեռ Approved չէ։

## Decision state

Արժեքի կարգավիճակը միայն այս բառերից մեկն է, կամ դատարկ.

| Decision state | Իմաստ |
| --- | --- |
| *(դատարկ)* | Որոշում չկա։ Պատճենած կաղապարը այս վիճակում է։ |
| `Candidate` | Դիտարկվող տարբերակ։ Իրականացումը չի թույլատրում։ |
| `Proposed` | Սեփականատիրոջը ներկայացված առաջարկ։ Դեռ հաստատված չէ։ |
| `Approved` | Սեփականատիրոջ հաստատած արժեք։ Միայն սա է թույլատրում այդ արժեքով շարունակել։ |
| `Rejected` | Մերժված տարբերակ։ Չի օգտագործվում։ |

Աշխատանքի նշանները. ⬜ չի սկսվել · 🔄 ընթացքում · ✅ պատրաստ · ➖ պետք չէ։

Նշում սյունակը գնահատման չափանիշ է։ Այն ընտրված արժեք չէ։ Զրույցի նախընտրությունը, կաղապարը և օրինակը Approved չեն դառնում, քանի դեռ սեփականատերը այդ արժեքը բացահայտ չի հաստատել այս քարտում։
