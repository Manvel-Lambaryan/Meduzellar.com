### Օգտատիրոջ հարցում

```
1. Օգտատեր → Frontend
2. Frontend → API (fetch/axios)
3. API → Վալիդացիա (DTO)
4. API → Սերվիս (բիզնես-լոգիկա)
5. Սերվիս → հաստատված տվյալների մուտք → ԲԴ
6. Պատասխան ← շղթայով
```
