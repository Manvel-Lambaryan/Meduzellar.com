# Custom AI v1.0 — Governance Alignment Notes

**Կարգավիճակ՝ Phase A · Architect Proposed corrections։** [Master Architecture](MEDUZELLAR_CUSTOM_AI_MASTER_ARCHITECTURE_HY.md)-ի պատմական կարգավիճակը պահպանված է։ Հաստատված դոմենային scope-ը և չփակված release սահմանը գրանցված են [ADR-012-ում](ADR-012-CUSTOM-AI-PLANNING-SIGN-OFF_HY.md)։

[AGENTS.md](../../AGENTS.md#decision-precedence)-ի security invariants-ը և workflow gates-ը գերակա են։ Պարտադիր են CORS allowlist-ը, CSRF պաշտպանությունը, tenant/resource server authorization-ը, արտաքին input validation-ը, parameterized queries-ը, անվտանգ password hashing-ը երբ պահվում է, գաղտնիքների պաշտպանությունը և redacted errors/logs-ը։ Չլուծված Critical dependency vulnerability-ն կանգնեցնում է ազդված աշխատանքը։ [Security rule](../../.cursor/rules/08-security.mdc)
