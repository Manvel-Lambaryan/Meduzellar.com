# Professional Network v1.0 — Governance Alignment Notes

**Կարգավիճակ՝ Phase A · Architect Proposed corrections։** [Master Architecture](MEDUZELLAR_PROFESSIONAL_NETWORK_MASTER_ARCHITECTURE_HY.md)-ի բովանդակությունը և պատմական կարգավիճակը պահպանվում են։ Owner-ի փաստացի հաստատման սահմանը գրանցված է [ADR-011-ում](ADR-011-PROFESSIONAL-NETWORK-PLANNING-SIGN-OFF_HY.md)։

[AGENTS.md](../../AGENTS.md#decision-precedence)-ի security invariants-ը և workflow gates-ը կիրառելի են բոլոր տարբերակներում։ Պարտադիր են CORS allowlist-ը, CSRF պաշտպանությունը, server-side authorization-ը, արտաքին input validation-ը, parameterized queries-ը, գաղտնիքների պաշտպանությունը և անվտանգ errors/logs-ը։ Պահվող գաղտնաբառերը պահանջում են անվտանգ hashing։ Չլուծված Critical dependency vulnerability-ն կանգնեցնում է ազդված աշխատանքը։ [Security rule](../../.cursor/rules/08-security.mdc)
