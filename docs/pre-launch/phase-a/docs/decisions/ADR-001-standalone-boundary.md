# ADR-001 Standalone module boundary

**Status** Accepted for repository boundary only · **Date** 2026-11-26 · **Decider** Product Owner

The official Option C directive approved project name Meduzellar Pre-Launch, repository name meduzellar-pre-launch, dedicated repository, Size A, isolated modular monolith direction and independent governance and deployment. The standalone working directory proposed in this package is `D:/meduzellar-pre-launch`.

An in-tree application and nested workspace would inherit the Platform's authorization gates. An external workspace without a dedicated repo would make review history and release ownership less clear. The accepted boundary establishes separate source control, credentials, identities, subscriber data and release ownership. It incurs a separate repository and requires explicit handoff of brand assets, sender domains and long-term retirement responsibility.

This record accepts the boundary facts. The charter, technology values and specific architecture await Phase A sign-off. Application initialization requires separate Phase B authorization. [Charter](../../AGENTS.md) · [Approval checklist](../PROGRESS.md)
