# Meduzellar Pre-Launch

Meduzellar Pre-Launch is a temporary Coming Soon site and verified email waitlist for the Meduzellar Platform. Visitors can register for the official launch announcement, verify their email, and unsubscribe. An authorized owner can preview, test, approve, pause, and monitor the campaign.

**Phase A planning package · Owner review pending · 2026-11-26**

The owner approved the standalone repository meduzellar-pre-launch, Size A, the isolated modular monolith direction, and independent governance and deployment. The technology and operating choices are proposed. The main Meduzellar Platform remains in Concept & Planning.

**Proposed standalone working tree** `D:/meduzellar-pre-launch`, a sibling of `D:/Meduzellar.com`. It is outside the current writable Platform workspace. This documentation package can be copied as a unit to the standalone repository root after a destination is authorized. The working tree and remote have yet to be created.
