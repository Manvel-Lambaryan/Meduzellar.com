# Նախագծի տեխզադրանք

> Աշխատանքային համառոտագիր [`README.md`](../README.md)-ից։ README-ն մնում է արտադրանքի աղբյուրը։
> Կարգավիճակ. **Concept & Planning**։ Նկարագրված հնարավորությունները տեսլական են, ոչ թե իրականացված համակարգ։

## 1. Արտադրանք

**Meduzellar Platform**-ը ընկերության առաջին և միակ ընթացիկ նախագիծն է։ Միջազգային հարթակ է մասնագետների, գործատուների և թվային արտադրանք ստեղծողների համար։

Մեկ հարթակ, հինգ դոմեն.

| Դոմեն | Պատասխանատվություն | Սահման |
| --- | --- | --- |
| Marketplace | Projects, Source Code, Plugins, Designs, Templates, Tools, Digital Assets | Հայտարարությունը աշխատանքի հայտարարություն չէ |
| Network և recruitment | Պրոֆիլ, հմտություններ, աշխատանք, դիմում, հարցազրույց | Հավաքագրման հոսքը չատի կամ զանգի տիրույթը չէ |
| Communication | Հաղորդագրություն, աուդիո, վիդեո, հարցազրույց, նախագծի հանդիպում | Զանգը չի տնօրինում թարգմանությունը կամ վարձումը |
| Realtime translation | Խոսք և չատ զրույցի ընթացքում, երկկողմանի | Սա ինտերֆեյսի i18n չէ |
| Custom assistant | Որոնում, առաջարկ, թույլատրված գործողության օգնություն | Գրառումների, աշխատանքի և հաղորդագրությունների աղբյուրը չէ |

Marketplace-ում գնված աշխատանքը կարող է շարունակվել նույն հարթակում. գտնել մասնագետ, կապ հաստատել, զանգել, թարգմանել, օգտագործել օգնականը։ Դա մեկ էկոհամակարգ է, ոչ թե հինգ առանձին արտադրանք։

## 2. Լսարան

Ծրագրավորողներ, դիզայներներ, մասնագետներ, գործատուներ, recruiter-ներ և թվային արտադրանք գնողներ։ Լսարանը միջազգային է։

## 3. Ինչն է որոշված

- Առաջին նախագիծը միայն Meduzellar Platform-ն է։ Հետագա ընկերության նախագծերը այս ռեպոյի շրջանակից դուրս են։
- Հինգ դոմենը վերևի աղյուսակով։
- Ինտերֆեյսը պետք է լինի բազմալեզու։ Զանգի և չատի թարգմանությունը առանձին համակարգ է և չի սահմանափակվում ինտերֆեյսի լեզուներով։
- Բրենդ. Meduzellar = Meduza + Stellar։ One Intelligent Core. Infinite Connections. Endless Possibilities.

## 4. Ինչը որոշված չէ

Սրանք չեն ընտրվում կաղապարի լռելյայնով։ Ամրագրվում են միայն հաստատված `docs/TECH_CARD.md`-ում։

- Նախագծի չափը՝ A / B / C, և թղթապանակների դասավորությունը։
- Framework, հոսթինգ, տվյալների բազա, auth։
- Վճարում, ֆայլերի պահոց, փոստ, realtime մեդիա։
- Թարգմանության և օգնականի մատակարարները։
- Ինտերֆեյսի մեկնարկային լեզուների ցանկը։
- Դիզայն և UI kit։ Ժամկետ չկա։

Բաց ճարտարապետական հարց. README-ն նշում է և Marketplace-ի անձնական/ընկերության պրոֆիլ, և մասնագիտական պրոֆիլ։ Մի հաշիվ մի քանի դերով, թե առանձին պրոֆիլներ, դեռ որոշված չէ։ Չստեղծել երկու օգտատիրոջ համակարգ և չմիացնել դրանք, քանի դեռ որոշումը չկա։

## 5. Աշխատանքի սահման

Application կոդ, սխեմա և vendor-ի բանալիներ չեն սկսվում, քանի դեռ չափը, stack-ը և ճարտարապետությունը հաստատված չեն։

Մեկնարկի workflow-ն [`project-onboarding`](../.agents/skills/project-onboarding/SKILL.md) skill-ն է։
